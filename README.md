

# EdgeDock —— 桌面边缘侧边栏快捷启动器

一个极简的 Windows 桌面侧边栏：平时隐藏为屏幕边缘一条细色条，鼠标碰上去（延迟可调）即平滑展开为应用图标网格，鼠标离开后自动收回。应用多时可上下平滑滚动，像手机侧边栏一样。

## 特性一览

| 需求 | 实现方式 |
|------|----------|
| 鼠标悬停展开 | 平时 6px 隐藏条，悬停 `show_delay_ms` 后平滑展开 |
| 自定义添加应用 | 右键 →「添加应用」选 exe/lnk；或编辑 config.json 的 `apps` |
| 图形化自定义 | 右键 →「设置…」打开设置面板，可视化修改全部参数，**无需改代码/JSON** |
| 每行/每列个数 | `columns` 控制每行个数；每列个数由 `dock_height` 决定，超出自动滚动 |
| 上下滑动 | 鼠标滚轮平滑滚动（按格累积），内容超高自动出现细滚动条 |
| 高清图标 | 优先提取 48px 大图标 + 超采样放大到 64px 显示，自动缓存到 `icons\` |
| 自定义宽高 | `dock_width` / `dock_height` |
| 背景颜色/图片 | `bg_color` / `bg_image`（png/gif，设置面板可浏览选择） |
| 显示/收起延迟 | `show_delay_ms` / `hide_delay_ms` |
| 隐藏条颜色 | `hidden_color` |
| 层级与透明 | `topmost` 置顶开关；`alpha` 半透明面板（0.5~1.0） |
| 悬停高亮 | 鼠标移到图标上高亮（`hover_color`） |
| 开机自启动 | 设置面板勾选或右键菜单切换，写当前用户 Run 注册表 |

## 运行方法

```bat
python edge_dock.py
```

免控制台窗口运行：双击 `start_edge_dock.bat`（使用 pythonw，无黑框）。

需要 Windows + Python 3.8+（自带 tkinter），**无任何第三方依赖**。

## 图形化设置（推荐）

展开侧边栏 → 在任意位置**右键** →「设置…」，弹出设置面板，可改：

- 侧边栏位置（左/右）、隐藏条宽度
- 展开延迟、收起延迟（毫秒）
- 每行应用数、面板宽度、面板高度
- 背景颜色、隐藏条颜色、文字颜色（带颜色选择器）
- 背景图片（浏览选择 / 清除）
- 面板透明度（滑块 0.5~1.0）
- 置顶显示、开机自启动（勾选）

点「保存并应用」立即生效；「取消」放弃修改。

## 配置文件说明（config.json，与脚本同目录）

首次运行自动生成，所有字段与设置面板一一对应，也可手动编辑后右键 →「重新加载配置」。

| 字段 | 默认值 | 说明 |
|------|--------|------|
| `dock_position` | `right` | 侧边栏位置：`left` / `right` |
| `hidden_width` | `6` | 平时隐藏条宽度（px） |
| `show_delay_ms` | `150` | 鼠标悬停到展开的延迟（毫秒） |
| `hide_delay_ms` | `500` | 鼠标离开到收起的延迟（毫秒） |
| `columns` | `4` | 每行显示多少个应用 |
| `padding` | `10` | 网格内边距（px） |
| `spacing` | `8` | 图标间距（px） |
| `dock_width` | `280` | 展开后窗口宽度（px） |
| `dock_height` | `420` | 展开后窗口高度（px）；应用多时自动滚动 |
| `bg_color` | `#1e1e2e` | 展开时背景颜色（HEX） |
| `bg_image` | `""` | 背景图片路径，留空为纯色 |
| `hidden_color` | `#3a3a4a` | 平时隐藏条颜色 |
| `text_color` | `#ffffff` | 应用名称文字颜色 |
| `hover_color` | `#4a4a6a` | 图标悬停高亮颜色 |
| `topmost` | `true` | 是否置顶显示（层级） |
| `alpha` | `1.0` | 展开面板透明度 0.5~1.0 |
| `autostart` | `false` | 是否开机自启动 |
| `apps` | 8 个系统应用 | 应用列表，每项 `{"name": 显示名, "path": 路径, "icon": 可选图标路径}` |

## 添加应用

方式一：展开侧边栏 → 右键 →「添加应用」→ 选择 `.exe` 或 `.lnk`，自动加入并刷新。

方式二：设置面板/编辑 `config.json` 的 `apps` 数组，保存后生效。

`path` 支持：exe 完整路径、`notepad.exe` 这类系统命令、`ms-settings:` 这类 URI、`.lnk` 快捷方式。

## 开机自启动

- 设置面板勾选「开机自启动」，或右键菜单一键切换；
- 原理：写入当前用户注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，不影响其他用户与系统。

## 图标显示

自动调用 Win32 `SHGetFileInfo`（48px 大图标）优先提取，失败回退 `ExtractIconEx`（32px），再超采样放大到 64px 高清显示，缓存到同目录 `icons\` 文件夹。无需 PIL 等依赖；提取失败时自动降级为文字色块。

## 体积与性能

- `edge_dock.py` 单文件约 35KB，仅标准库，无安装包；
- 平时为纯事件驱动：不占 CPU，内存占用约 15~30MB（tkinter 基础开销）；
- 不修改任何系统文件、不注入进程，退出即完全释放。

## 常见问题

- **展开后看不到**：检查 `topmost` 是否开启，或当前是否有全屏应用盖住（可用 Win+D 回到桌面测试）。
- **背景图片不显示**：仅支持 png/gif，路径需为绝对路径或相对脚本目录的路径。
- **滚轮不滚动**：鼠标需停留在侧边栏图标区域内滚动；应用数超过面板容量才会出现滚动。
- **移动位置**：整个文件夹复制到任意路径均可运行（配置、图标缓存均在脚本同目录）。
